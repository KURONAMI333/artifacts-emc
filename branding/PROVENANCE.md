# CurseForge icon provenance and credits

`icon.png` is a 512×512 icon for this addon. Its central Philosopher's Stone is from KURONAMI's existing EMC series master sprite. The frame was drawn by this addon's maintainers. The Cloud in a Bottle and Golden Hook textures were taken from the official Artifacts 13.2.5 NeoForge JAR (`assets/artifacts/textures/item/cloud_in_a_bottle.png` and `assets/artifacts/textures/item/golden_hook.png`, release JAR SHA-256 `e36a929420a0a616abdb28f5bbbdb866a426aa3bb78d1b39bc1183927c101ce6`).

Artifacts is by Wouter Pauwels (ochotonida) and its JAR metadata declares `license="MIT"`. The complete upstream MIT notice is in [ARTIFACTS_MIT_LICENSE.txt](ARTIFACTS_MIT_LICENSE.txt), taken from [the official repository at commit 4b67278](https://github.com/ochotonida/artifacts/blob/4b67278df94e4d3669119f1abb24a1c3a758afe1/LICENSE). KURONAMI's addon license applies to the addon source and binary; the Artifacts textures retain their upstream MIT terms.

This branding PNG is a separate CurseForge avatar candidate. It is not embedded in the current 0.1.0 JAR.
